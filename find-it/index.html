    어디 있을까? — 빠른 찾기 인덱스¶

    자주 묻는 질문 + 자주 찾는 위치를 한 페이지에 모았습니다. 메뉴를 9 개씩 뒤지지 말고 여기서 Ctrl+F (찾기) 로 키워드 검색.

    🚀 시작하기¶

    상황 어디로
    처음 시작, 무엇부터 해야 하지 docs/getting-started/00-claude-code-quickstart.md (AI 안내) 또는 01 하드웨어 연결
    Claude Code 가 무엇입니까 00 Claude Code 시작
    URL 만 받았는데 어떻게 진행 00 페이지 - ZIP 받기 전 OK 박스
    환경 구축 단계가 막혔습니다 02 환경 구축 → troubleshooting.md
    첫 빌드가 안 됩니다 03 첫 빌드 + troubleshooting.md
    LED 가 안 켜집니다 Ex.00 Quick Start README

    🛠️ 코드 작성¶

    상황 어디로
    내 코드 어디에 쓰지 XM_Apps/Control_Task/control_task.c (ZIP 압축 푼 폴더 기준)
    내 코드가 언제 호출되는지 docs/architecture/README.md
    함수 시그니처 / API 명세 docs/api-reference/
    버튼 / LED 제어 api-reference/03-led-btn-control.md + Ex.01~03
    외부 GPIO / ADC api-reference/04-external-io.md + Ex.04~06
    USB 시리얼로 PC 에 데이터 보내기 api-reference/05-usb-connectivity.md + Ex.07~09
    USB 로 데이터 내보내기 (실시간) api-reference/05-usb-connectivity.md + Ex.09 CDC Stream · PhAI Studio
    메모리 영역 (PSRAM, Workspace) api-reference/07-memory-management.md + Ex.19
    날짜·시간 (RTC) api-reference/08-rtc-clock.md
    KIT H10 외골격 제어 api-reference/02-h10-control-n-data.md + Ex.11~13
    상태 머신 (TSM) api-reference/01-task-state-machine.md + Ex.03
