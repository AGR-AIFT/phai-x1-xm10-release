    XM10 Extension Module SDK v2.2.1¶

    릴리즈 날짜: 2026-05-19 | 대상 HW: Rev 1.1 / Rev 2.0 | KIT H10 FW: v2.3.0+

    한눈에 보기¶

    다운로드한 SDK 가 STM32CubeIDE clean build 에서 "undefined reference" 22 건으로 실패하던 문제를 수정한 패치 릴리즈 입니다. 라이브러리 빌드 단계에서 일부 모듈의 소스가 누락되어 있던 게 원인이었습니다.

    • Rev 2.0 SDK: 새 libXM_Lib.a 로 교체. clean build 169/169 link 통과 확인
    • Rev 1.1 SDK: 같은 정합성 차원의 작은 수정 (FreeRTOS 설정 + USB MSC 진단 함수)
    • 보드 리비전 비교 문서 보강 — 본인 보드와 다른 ZIP 으로 빌드하면 내장 버튼/LED 핀이 한 칸 어긋난다는 점이 어디에도 명시되어 있지 않던 문제

    기존 사용자 코드는 그대로 동작합니다. API / 동작 변경 없음, 빌드 환경 그대로. v2.2.0 으로 빌드가 됐던 분은 굳이 받지 않으셔도 되고, 빌드가 안 됐던 분은 본 ZIP 으로 다시 받아주세요.

    다운로드¶

    파일 대상 보드
    Rev1.1.zip XM10 Rev 1.1 (초기 개발용 보드)
    Rev2.0.zip XM10 Rev 2.0 (Ethernet / PSRAM / RTC 포함 최신 보드)

    압축을 풀면 한 폴더가 나옵니다. 그 폴더가 곧 STM32CubeIDE Import root + Claude Code 진입 폴더입니다.

    본인 보드 리비전과 같은 ZIP 을 받아주세요. 라벨이 모호하면 외관상 RJ45 Ethernet 포트가 있으면 Rev 2.0, 없으면 Rev 1.1 입니다. 다른 Rev 의 ZIP 으로 빌드하면 빌드는 통과해도 내장 버튼/LED 의 MCU 핀 매핑이 한 칸 어긋납니다. 자세한 비교는 docs/hardware/README.md - 보드 리비전 비교.

    Release 첨부 파일¶

    부트로더 / KIT H10 펌웨어 / 컨텐츠 파일은 v2.2.0 과 동일합니다. v2.2.0 에서 받아서 설치하셨다면 v2.2.1 에서 다시 받지 않으셔도 됩니다. 처음 v2.2.1 부터 시작하시는 분만 아래 자산도 함께 다운로드.

    파일 설명
    AGR_Bootloader.bin XM10 부트로더 (v1.1.0). 0x08000000 에 한 번만 설치하면 됩니다. (이미 설치되어 있는 보드는 건너뛰기)
    SUIT_FW_ContentsFiles_20260518.zip/SUIT_CM_APP_X_X_X.bin KIT H10 CM 펌웨어. USB-C 메모리로 직접 업데이트 필요.
    SUIT_FW_ContentsFiles_20260518.zip/SUIT_SAM10_APP_X_X_X.bin KIT H10 MD(SAM10) 펌웨어.
    SUIT_FW_ContentsFiles_20260518.zip/SUIT_ESP32_FW_X_X_X.bin KIT H10 ESP32 펌웨어.
    SUIT_FW_ContentsFiles_20260518.zip/SUIT_ContentsFiles.zip KIT H10 컨텐츠파일. SD card 에 직접 폴더 전체 교체 필요.

    자세한 업데이트 절차는 docs/kit-h10-firmware/ 참고.

    수정 내용¶

    1. Rev 2.0 SDK 빌드 실패 22 건 수정¶

    다운로드 직후 STM32CubeIDE clean build 에서 다음 패턴의 link error 가 22 건 발생하던 문제를 수정했습니다.

    undefined reference to `CdcDopRouter_Init'
undefined reference to `CdcDopRouter_Process'
undefined reference to `USBH_DiskIO_GetDiag'
undefined reference to `USBH_DiskIO_ResetDiag'
undefined reference to `XM_Ethernetif_GetMdioId'
undefined reference to `g_eth_rx_packet_count'
undefined reference to `xTaskGetHandle'
... (총 22 건)

    새 libXM_Lib.a 와 sync 된 소스로 교체했고, clean build 169/169 link 통과를 확인했습니다.

    2. Rev 1.1 SDK 안정성 개선¶

    Rev 1.1 자체는 link 실패가 없었지만, 라이브러리가 호출하는 함수 중 일부가 SDK 트리에서 누락되어 있던 작은 정합성 문제를 함께 해결했습니다.

    • Compatible/FATFS/Target/usbh_diskio.c — USB MSC 진단 함수 정의 복원
    • Core/Inc/FreeRTOSConfig.h — INCLUDE_xTaskGetHandle = 1 매크로 추가

    3. 보드 리비전 비교 문서 보강¶

    본인 보드 리비전을 확인하는 진입점이 깨진 링크로 가던 문제를 정리하고, 비어 있던 비교 표를 채웠습니다.

    • docs/hardware/README.md — 내장 버튼 표에 Rev 별 MCU 핀 컬럼 추가 + 비교표 본문 채움 (RJ45 / 채널 LED / PSRAM / 버튼 핀 / ZIP 매핑)
    • examples/README.md — 본인 Rev 와 다른 ZIP 사용 시 증상 안내
    • docs/api-reference/03-led-btn-control.md — "흔한 실수" 표에 Rev mismatch 항목
    • docs/troubleshooting.md — "보드 리비전 / SDK ZIP 불일치" 신규 섹션 (증상, 핀 표, 진단 코드, 해결 단계)
    • README.md / CLAUDE.md / docs/find-it.md — 깨진 architecture 비교표 링크를 새 hardware/README 비교표로 통일

    호환성 안내¶

    항목 영향
    사용자 코드 (Control_Setup / Loop) 변경 없음 — v2.2.0 코드 그대로 빌드 가능
    API 시그니처 변경 없음 — 헤더 변경 없음
    KIT H10 펌웨어 v2.3.0 그대로 — 동반 펌웨어 업데이트 불필요
    사용자 데이터 (USB 메모리 로그 등) 변경 없음 — 데이터 포맷 호환

    v2.2.0 으로 빌드가 잘 됐던 분은 본 v2.2.1 로 굳이 갈 필요 없습니다 (라이브러리 내부만 정합성 보강). 빌드가 안 됐던 분은 본 ZIP 으로 받아주세요.
