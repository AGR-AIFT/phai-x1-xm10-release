    XM10 Extension Module SDK v2.3.0¶

    릴리즈 날짜: 2026-07-15 | 대상 HW: Rev 1.1 / Rev 2.0 | KIT H10 FW: v2.3.0+

    한눈에 보기¶

    센서 허브 연동 예제 2 종을 새로 추가하고, SDK 안의 펌웨어·예제를 개발 원본과 완전히 같은 상태로 다시 맞춘 마이너 릴리즈 입니다.

    • Ex.41 IMU Hub Dashboard · Ex.42 EMG Hub Biofeedback 추가 (둘 다 Rev 2.0 전용)
    • SDK 안의 펌웨어 (libXM_Lib.a) 와 시스템 코드 (Core/) 를 개발 원본과 다시 정합 — 그동안 SDK 에만 남아 있던 예전 상태를 최신 펌웨어로 갱신했습니다. 릴리즈 SDK 로 빌드한 결과가 개발 펌웨어와 동일하게 동작하도록 맞췄습니다.
    • 제어·로깅 예제의 실동작 버그 정리 (Ex.12 / 17 / 28 제어, Ex.10 / 10c 로깅 등)
    • version.h 를 실제 릴리즈 버전 (2.3.0) 으로 정정 — v2.2.1 / v2.2.2 패치 때 누락돼 2.2.0 으로 보고되던 갭 해소
    • 예제 build sweep: Rev 2.0 SDK 50 / 50 · Rev 1.1 SDK 47 / 47 클린빌드 통과 확인

    기존 사용자 코드는 그대로 동작합니다. 사용자 코드 (Control_Setup / Control_Loop) 와 공개 API 시그니처 변경 없음.

    다운로드¶

    파일 대상 보드
    Rev1.1.zip XM10 Rev 1.1 (초기 개발용 보드)
    Rev2.0.zip XM10 Rev 2.0 (Ethernet / PSRAM / RTC 포함 최신 보드)

    압축을 풀면 한 폴더가 나옵니다. 그 폴더가 곧 STM32CubeIDE Import root + Claude Code 진입 폴더입니다.

    본인 보드 리비전과 같은 ZIP 을 받아주세요. 라벨이 모호하면 외관상 RJ45 Ethernet 포트가 있으면 Rev 2.0, 없으면 Rev 1.1 입니다. 자세한 비교는 docs/hardware/README.md - 보드 리비전 비교.

    Release 첨부 파일¶

    부트로더 / KIT H10 펌웨어 / 컨텐츠 파일은 v2.2.x 와 동일합니다. 이전 릴리즈에서 이미 설치하셨다면 다시 받지 않으셔도 됩니다. 처음 v2.3.0 부터 시작하시는 분만 함께 다운로드.

    파일 설명
    AGR_Bootloader.bin XM10 부트로더 (v1.1.0). 0x08000000 에 한 번만 설치하면 됩니다.
    SUIT_FW_ContentsFiles_*.zip/SUIT_CM_APP_X_X_X.bin KIT H10 CM 펌웨어. USB-C 메모리로 직접 업데이트.
    SUIT_FW_ContentsFiles_*.zip/SUIT_SAM10_APP_X_X_X.bin KIT H10 MD(SAM10) 펌웨어.
    SUIT_FW_ContentsFiles_*.zip/SUIT_ESP32_FW_X_X_X.bin KIT H10 ESP32 펌웨어.
    SUIT_FW_ContentsFiles_*.zip/SUIT_ContentsFiles.zip KIT H10 컨텐츠파일. SD card 폴더 전체 교체.

    업데이트 절차: docs/kit-h10-firmware/.

    새 예제 — 센서 허브 연동 2 종 (Rev 2.0 전용)¶

    XM10 Rev 2.0 은 FDCAN2 로 IMU Hub / EMG Hub 모듈과 연결됩니다. 두 예제는 허브를 꽂고 XM10 에 연결만 하면 데이터가 자동으로 들어온다는 점 (plug-and-play) 을 보여주고, 그 데이터를 on-device 로 가공·피드백하는 흐름을 담았습니다.

    • Ex.41 IMU Hub Dashboard ⭐⭐⭐ — IMU Hub Module 최대 6 채널의 방위 (쿼터니언) 를 받아 오일러 각 (roll / pitch / yaw) 으로 변환합니다. 연결 자동감지 (connected mask) + LED 표시 + PhAI Studio 18 채널 스트리밍. 관찰형 예제라 모터를 쓰지 않아 안전하게 자세 데이터를 다뤄볼 수 있습니다.
    • Ex.42 EMG Hub Biofeedback ⭐⭐⭐ — EMG Hub Module 의 근활성도 (envelope / MVC%) 를 받아 MVC 정규화 캘리브레이션 (BTN) 을 수행하고, 근활성도에 비례해 LED / PhAI Studio 로 바이오피드백을 줍니다. 모터 없음.

    IMU / EMG Hub 모듈의 센서 캘리브레이션·설정은 자체 진단 GUI (PhEEL Studio, 공개 예정) 로도 조정할 수 있습니다. 두 예제 README 에 연동 화면 자리를 마련해 두었습니다.

    SDK 정합 — 개발 원본과 "동작 동일"¶

    SDK 는 개발용 펌웨어를 정적 라이브러리 (libXM_Lib.a) 로 감싸 배포합니다. 이번 릴리즈에서 SDK 안의 라이브러리·시스템 코드 (Core/) · 헤더를 개발 원본의 최신 상태로 다시 맞췄습니다.

    • 펌웨어 (libXM_Lib.a) 재빌드 — 개발 원본과 바이트 단위로 동일함을 확인.
    • 시스템 코드 (Core/) 정합 — 그동안 SDK 에만 예전 상태로 남아 있던 인터럽트 우선순위 / fault 처리 / RTOS 설정을 최신 펌웨어와 일치시켰습니다.
    • 예제 소스 정합 — 개발 원본과 예제 .c 를 다시 동기화 (Rev 2.0 SDK 50 종 · Rev 1.1 SDK 47 종).
    • 최종 검증 — Rev 2.0 / Rev 1.1 SDK 각각 클린빌드 0 error 로, 릴리즈 SDK 가 개발 펌웨어와 동일하게 빌드·동작함을 확인했습니다.

    예제 실동작 정리¶

    • Ex.28 (Admittance) — 어드미턴스 토크가 좌/우 계산 완료 전에 인가되던 순서 정정 (좌우 각각 계산 후 인가).
    • Ex.17 (FSM Gait Intent) — 체중 파라미터 단위 (g) 및 레벨 스케일 계수 정정.
    • Ex.12 (Active Assist) — 앵커 각도 스케일 (×10) 정정.
    • Ex.10 / 10c (MSC Log) — 로그 시작을 진입 (on_entry) 시점으로 정합 + 시작 실패 시 안전 복귀.
    • 진입점 주석 (Control_Setup / Control_Loop) · 난이도 표기 일관화.

    version.h 2.3.0 정합¶

    version.h 가 v2.2.1 / v2.2.2 패치 때 bump 되지 않아 그동안 펌웨어 버전이 2.2.0 으로 보고되고 있었습니다. 이번 릴리즈에서 실제 릴리즈 버전에 맞춰 2.3.0.0 으로 정정했습니다 (Rev 1.1 / Rev 2.0 공통).

    사용자 데이터 (USB 메모리 로그 등) 변경 없음 — 데이터 포맷 호환
