# XM10 Extension Module SDK v2.3.1

> **릴리즈 날짜**: 2026-07-18 | **대상 HW**: Rev 1.1 / Rev 2.0 | **KIT H10 FW**: v2.3.0+

---

## 한눈에 보기

**부팅·통신 안정성과 SDK 사용성을 다듬은 패치 릴리즈**입니다. 새 예제나 API 추가는 없습니다.

- **GRF(족저 압력) 센서 모듈 연결 시 부팅 안정성 개선** — 센서 전원을 부팅 후 단계적으로 인가하도록 바꿔, 모듈을 꽂은 채 전원을 켤 때 보드가 재부팅을 반복할 수 있던 문제를 완화했습니다. 데이터 수신 경로도 손봐 수신 누락을 제거했습니다.
- **제어·통신·저장 내부 안정성 수정 다수** — CAN 버스 회복, USB 연결 해제 처리, 로그 버퍼 배치, 메모리 접근 경계 검사 등을 보강했습니다.
- **ZIP 받아서 CubeIDE 로 바로 빌드** — 압축 해제 → import 직후 빌드가 실패하던 포장 결함(헤더 경로 누락, 빌드 스크립트 누락)을 수정했고, 빌드 결과가 **0 error / 0 warning** 이 되도록 정리했습니다.
- **버전 표기 안정화** — ZIP 프로젝트에서 빌드 후 펌웨어 버전이 1.0.0.0 으로 바뀌던 문제를 수정했습니다. 이제 항상 릴리즈 버전(2.3.1)이 유지됩니다.

## ⚠️ 동작 변경 — 고관절 토크 값의 단위

`XM.status.h10.leftHipTorque` / `rightHipTorque` 가 이제 **모터 전류(A)가 아니라 관절 토크(Nm)** 를 담습니다.

- 코드에서 직접 `× 0.085 × 18.75` 환산을 하고 있었다면 **환산을 제거**하고 필드 값을 그대로 사용하세요.
- Ex.31 (Friction DOB) / Ex.34 (Gait Log) 예제는 이번 릴리즈에서 이에 맞게 갱신되어 있습니다.

## 제거된 API

`XM_GetUserPSRAM()` / `XM_GetUserPSRAMSize()` 가 공개 API에서 제외되었습니다. 대용량 버퍼가 필요하면 `XM_GetUserWorkspace()`(RAM_D1, 200KB)를 사용하세요 — [07. 메모리 영역](https://github.com/AGR-EXO/Extension_Module/blob/v2.3.1/docs/api-reference/07-memory-management.md) 참고.

빌드 마무리 단계(업로드용 `.bin` 생성)가 **Python** 을 사용합니다. 아직 설치하지 않았다면 [개발 환경 구축](https://github.com/AGR-EXO/Extension_Module/blob/v2.3.1/docs/getting-started/02-software-setup.md) 의 안내대로 Python 3.10+ 를 설치해 주세요 (PATH 등록 필수).

## 개선 상세

- **GRF 센서 모듈 부팅 안정성** — 센서 전원 레일을 부팅 완료 후 지연·단계 인가. 모듈을 꽂은 채 전원 인가 시 반복 재부팅 완화 (근본 원인은 하드웨어 전원 계통으로, 회로 개선과 병행 진행 중).
- **GRF 데이터 수신** — 수신 누락(드랍) 제거.
- **CAN 통신 견고화** — 버스 오류 상태에서 자동 회복 경로 정비, 전송 상태 관리 보강.
- **USB 안정성** — 케이블 분리/재연결 처리 개선, 데이터 패킷 길이 검사 보강.
- **저장·메모리** — 로그 버퍼 배치 재정리(네트워크 기능과의 메모리 충돌 예방), 설정 저장(Flash) 접근 경계 검사 추가.
- **제어 안전** — 리미트 스위치 예제(Ex.06) 입력 설정 안전화, 자세 센서 데이터 파싱 경계 검사, RTC 시각 설정 검증 등.
- **프로젝트 정리** — 쓰이지 않던 중복 빌드 설정 제거, 미사용 변수 경고 제거. CubeIDE 빌드 = 0 error / 0 warning.

## 호환성 안내

| 항목 | 영향 |
|------|------|
| 사용자 코드 (`Control_Setup` / `Control_Loop`) | **대부분 변경 없음** — 단, `leftHipTorque`/`rightHipTorque` 를 직접 환산해 쓰던 코드는 위 ⚠️ 참고 |
| `XM_GetUserPSRAM` 계열 | **제거** — `XM_GetUserWorkspace()` 로 대체 |
| 그 외 API 시그니처 | 변경 없음 |
| KIT H10 펌웨어·컨텐츠 파일 | **v2.3.0 그대로** — 추가 업데이트 불필요 |
| 부트로더 | **v1.1.0 그대로** — 재설치 불필요 |
| 사용자 데이터 (USB 메모리 로그 등) | 변경 없음 — 데이터 포맷 호환 |
