# XM10 Extension Module SDK v2.3.0

> **Release date**: 2026-07-15 | **Target HW**: Rev 1.1 / Rev 2.0 | **KIT H10 FW**: v2.3.0+

---

## At a Glance

**This is a minor release that adds two sensor-hub example programs and brings the firmware, system code, and examples inside the SDK fully up to date with each other.**

- Added **Ex.41 IMU Hub Dashboard** and **Ex.42 EMG Hub Biofeedback** (both **Rev 2.0-only**)
- Updated the SDK's firmware library (`libXM_Lib.a`) and system code (`Core/`) to the latest version — fixing places where some system code had fallen behind the library. Every file in an SDK build is now on the same version.
- Fixed runtime behavior in control/logging examples (Ex.12 / 17 / 28 control, Ex.10 / 10c logging, etc.)
- Corrected `version.h` to the actual release version (**2.3.0**) — the version number had not been updated in the v2.2.1 / v2.2.2 patches, so the firmware kept reporting 2.2.0
- Verified every example builds: Rev 2.0 SDK 50 / 50 · Rev 1.1 SDK 47 / 47 with zero errors

**Existing user code continues to work as-is.** No changes to user code (`Control_Setup` / `Control_Loop`) or public API signatures.

## New Examples — Two Sensor-Hub Programs (Rev 2.0-only)

XM10 Rev 2.0 connects to the IMU Hub / EMG Hub modules over FDCAN2. These two examples show that once you **plug a hub into XM10 and connect it**, data arrives automatically (plug-and-play), and then process/feed that data back on-device.

- **Ex.41 IMU Hub Dashboard** ⭐⭐⭐ — Receives orientation (quaternions) from up to 6 channels of the IMU Hub Module and converts them to Euler angles (roll / pitch / yaw). Connection auto-detection (connected mask) + LED indication + 18-channel PhAI Studio streaming. An observation-only example with no motor, so you can safely explore posture data.
- **Ex.42 EMG Hub Biofeedback** ⭐⭐⭐ — Receives muscle activation (envelope / MVC%) from the EMG Hub Module, performs MVC-normalization calibration (BTN), and provides LED / PhAI Studio biofeedback proportional to activation. No motor.

> Sensor calibration and settings for the IMU / EMG Hub modules can also be adjusted from the dedicated diagnostic GUI (**PhEEL Studio**, coming soon). Both example READMEs include a placeholder for the companion screen.

## SDK Refresh — Library, System Code, and Examples on One Version

The SDK ships the XM10 firmware core as a static library (`libXM_Lib.a`). This release brings the library, system code (`Core/`), headers, and examples onto the same v2.3.0 firmware.

- **Firmware library (`libXM_Lib.a`) updated** — rebuilt from the v2.3.0 firmware.
- **System code (`Core/`) updated** — interrupt priorities / fault handling / RTOS configuration that had fallen behind are now matched to the library.
- **Example sources updated** — example `.c` files refreshed to the latest content (Rev 2.0 SDK 50 · Rev 1.1 SDK 47).
- **Final check** — each SDK (Rev 2.0 / Rev 1.1) was rebuilt from scratch with 0 errors, verifying that no header, library, or system-code mismatch remains.

## Example Runtime Fixes

- **Ex.28 (Admittance)** — Fixed ordering where admittance torque was applied before the left/right computation completed (now computed per side, then applied).
- **Ex.17 (FSM Gait Intent)** — Corrected the body-mass parameter unit (g) and the level scale factor.
- **Ex.12 (Active Assist)** — Corrected the anchor-angle scale (×10).
- **Ex.10 / 10c (MSC Log)** — Log start now happens at state entry (on_entry) + safe fallback on start failure.
- Unified entry-point comments (`Control_Setup` / `Control_Loop`) and difficulty markers.

---

## `version.h` Corrected to 2.3.0

`version.h` was not updated during the v2.2.1 / v2.2.2 patches, so the firmware had been reporting version **2.2.0**. This release corrects it to **2.3.0.0** (Rev 1.1 / Rev 2.0 alike).
