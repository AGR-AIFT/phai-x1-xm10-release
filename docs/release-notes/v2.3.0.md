# XM10 Extension Module SDK v2.3.0

> **릴리즈 날짜**: 2026-07-15 | **대상 HW**: Rev 1.1 / Rev 2.0 | **KIT H10 FW**: v2.3.0+

---

## 한눈에 보기

**센서 허브 연동 예제 2 종을 새로 추가하고, SDK 안의 펌웨어·시스템 코드·예제를 모두 최신 버전으로 다시 맞춘 마이너 릴리즈** 입니다.

- **Ex.41 IMU Hub Dashboard** · **Ex.42 EMG Hub Biofeedback** 추가 (둘 다 **Rev 2.0 전용**)
- SDK 안의 펌웨어 라이브러리 (`libXM_Lib.a`) 와 시스템 코드 (`Core/`) 를 최신 상태로 갱신 — 일부 시스템 코드가 이전 버전 그대로 남아 라이브러리와 어긋날 수 있던 부분을 바로잡았습니다. 이제 SDK 로 빌드한 펌웨어는 어느 파일 하나 버전이 어긋나지 않습니다.
- 제어·로깅 예제의 동작 버그 수정 (Ex.12 / 17 / 28 제어, Ex.10 / 10c 로깅 등)
- `version.h` 를 실제 릴리즈 버전 (**2.3.0**) 으로 정정 — v2.2.1 / v2.2.2 때 버전 숫자가 갱신되지 않아 펌웨어가 2.2.0 으로 표시되던 문제를 바로잡았습니다
- 전체 예제 빌드 확인: Rev 2.0 SDK 50 / 50 · Rev 1.1 SDK 47 / 47 오류 없이 통과

**기존 사용자 코드는 그대로 동작합니다.** 사용자 코드 (`Control_Setup` / `Control_Loop`) 와 공개 API 시그니처 변경 없음.

## 새 예제 — 센서 허브 연동 2 종 (Rev 2.0 전용)

XM10 Rev 2.0 은 FDCAN2 로 IMU Hub / EMG Hub 모듈과 연결됩니다. 두 예제는 허브를 **꽂고 XM10 에 연결만 하면** 데이터가 자동으로 들어온다는 점 (plug-and-play) 을 보여주고, 그 데이터를 보드 위에서 바로 가공해 피드백까지 주는 흐름을 담았습니다.

- **Ex.41 IMU Hub Dashboard** ⭐⭐⭐ — IMU Hub Module 최대 6 채널의 방위 (쿼터니언) 를 받아 오일러 각 (roll / pitch / yaw) 으로 변환합니다. 연결 자동감지 (connected mask) + LED 표시 + PhAI Studio 18 채널 스트리밍. 관찰형 예제라 모터를 쓰지 않아 안전하게 자세 데이터를 다뤄볼 수 있습니다.
- **Ex.42 EMG Hub Biofeedback** ⭐⭐⭐ — EMG Hub Module 의 근활성도 (envelope / MVC%) 를 받아 MVC 정규화 캘리브레이션 (BTN) 을 수행하고, 근활성도에 비례해 LED / PhAI Studio 로 바이오피드백을 줍니다. 모터 없음.

> **IMU Hub · EMG Hub Module 은 엔젤로보틱스가 자체 개발한 연구용 프로토타입 모듈**입니다. 아직 정식 제품화 전 단계로 상세 스펙 공개 전이며, 구매·이용 문의는 [onephai.com](https://onephai.com/) 으로 부탁드립니다.

> IMU / EMG Hub 모듈의 센서 캘리브레이션·설정은 자체 진단 GUI (**PhEEL Studio**, 공개 예정) 로도 조정할 수 있습니다. 두 예제 README 에 연동 화면 자리를 마련해 두었습니다.

## SDK 최신화 — 라이브러리·시스템 코드·예제 버전 일치

SDK 는 XM10 펌웨어 코어를 정적 라이브러리 (`libXM_Lib.a`) 로 담아 배포합니다. 이번 릴리즈에서 라이브러리·시스템 코드 (`Core/`) · 헤더·예제가 모두 같은 v2.3.0 펌웨어를 가리키도록 다시 맞췄습니다.

- **펌웨어 라이브러리 (`libXM_Lib.a`) 갱신** — v2.3.0 펌웨어로 새로 빌드했습니다.
- **시스템 코드 (`Core/`) 갱신** — 이전 버전 그대로 남아 있던 인터럽트 우선순위 / fault 처리 / RTOS 설정을 라이브러리와 일치시켰습니다.
- **예제 소스 갱신** — 예제 `.c` 를 최신 내용으로 업데이트했습니다 (Rev 2.0 SDK 50 종 · Rev 1.1 SDK 47 종).
- **최종 확인** — Rev 2.0 / Rev 1.1 SDK 를 각각 처음부터 다시 빌드해 오류 0 을 확인했습니다. 헤더·라이브러리·시스템 코드가 서로 어긋나 생기는 빌드 문제가 없는지 전체를 함께 검증했습니다.

- 진입점 주석 (`Control_Setup` / `Control_Loop`) · 난이도 표기 일관화.

## `version.h` 버전 표기 정정

`version.h` 가 v2.2.1 / v2.2.2 패치 때 bump 되지 않아 그동안 펌웨어 버전이 **2.2.0** 으로 보고되고 있었습니다. 이번 릴리즈에서 실제 릴리즈 버전에 맞춰 **2.3.0.0** 으로 정정했습니다 (Rev 1.1 / Rev 2.0 공통).

## 호환성 안내

| 항목 | 영향 |
|------|------|
| 사용자 코드 (`Control_Setup` / `Control_Loop`) | **변경 없음** — 기존 코드 그대로 빌드 가능 |
