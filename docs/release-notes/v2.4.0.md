# XM10 Extension Module SDK v2.4.0

> **릴리즈 날짜**: 2026-07-21 | **대상 HW**: **Rev 2.0 전용** | **KIT H10 FW**: v2.3.0+

---

## 한눈에 보기

**USB 시리얼 사용성을 크게 개선한 Rev 2.0 릴리즈**입니다. 일반 시리얼 터미널에서 예제의 텍스트 출력이 보이지 않던 문제를 근본적으로 해결했고, 그 과정에서 USB 통신 모드 API를 더 단순한 형태로 정리했습니다.

- **일반 터미널에서 텍스트 예제가 바로 보입니다** — 이전에는 Ex.07~09 같은 텍스트 예제를 Tera Term · VS Code Serial Monitor · PuTTY 로 열면, 보드가 PhAI Studio 용 실시간 데이터를 계속 내보내 텍스트가 묻혀 보이지 않았습니다(터미널의 DTR 신호를 수동으로 꺼야 했음). 이제 텍스트 예제가 **터미널 프로파일을 자동 지정**해, 별도 조작 없이 깨끗한 텍스트만 출력합니다.
- **USB 통신 모드 API 단순화** — 새 함수 `XM_USB_SetHostProfile()` 하나로 "PhAI Studio 로 쓸지 / 일반 터미널로 쓸지"만 고르면 됩니다. (아래 ⚠️ **API 변경** 참고 — 기존 `XM_USB_SetMode()` 계열은 제거되었습니다.)
- **부트로더 디버그 안내 보강** — 디버그 설정에서 벡터 테이블 주소(`0x08040400`)를 명시하도록 문서를 보강했고, 디버그 시작 시 `main()` 에서 멈추는 것이 정상 동작임을 안내했습니다.
- **안정성·빌드 개선** — GRF 센서 모듈 안정성 추가 개선, MCU 리셋 핀 처리 정리, CubeIDE 빌드 파이프라인 견고화.

## ⚠️ API 변경 — USB 통신 모드 (Rev 2.0)

USB-CDC 통신 모드를 다루는 API가 **더 단순한 프로파일 방식으로 교체**되었습니다.

**제거된 API** (Rev 2.0 헤더에서 삭제):

- 함수: `XM_USB_GetMode()` · `XM_USB_SetMode()` · `XM_USB_RegisterModeChangeCallback()`
- 타입: `XM_USB_Mode_e` · `XM_USB_ModeChangeCb_t`

**대체 API**:

```c
void XM_USB_SetHostProfile(XM_USB_HostProfile_e profile);

typedef enum {
    XM_USB_HOST_PHAI_STUDIO = 0,  // 기본값 — PhAI Studio 실시간 스트리밍
    XM_USB_HOST_TERMINAL    = 1,  // 일반 터미널 / 커스텀 프로그램 (auto-pump OFF)
} XM_USB_HostProfile_e;
```

**마이그레이션** — 이전에 터미널 용도로 모드를 직접 바꾸던 코드가 있다면 아래처럼 한 줄만 바꿔주세요:

```c
// 이전 (v2.3.1)
XM_USB_SetMode(XM_USB_MODE_TERMINAL);

// 이후 (v2.4.0)
XM_USB_SetHostProfile(XM_USB_HOST_TERMINAL);
```

- **미호출 시 기본값은 `XM_USB_HOST_PHAI_STUDIO`** 이므로, 모드를 따로 만지지 않던 코드는 **변경 없이 그대로** 동작합니다(기존 PhAI Studio 스트리밍 유지).
- 생산 검사(PRODUCTION) 모드는 이제 **보드 내부에서 자동으로 처리**되어 사용자 선택지에서 빠졌습니다 — 예제/사용자 코드에서 신경 쓸 필요가 없습니다.
- 선택한 프로파일은 **케이블 재연결(DTR 재토글)에도 유지**됩니다.

### Release 첨부 파일

> **부트로더 · KIT H10 펌웨어 · 컨텐츠 파일은 v2.3.0 과 동일**하며, 편의를 위해 [v2.4.0 릴리즈](https://github.com/AGR-EXO/Extension_Module/releases/tag/v2.4.0)에도 같은 파일을 그대로 첨부했습니다 (`AGR_Bootloader.bin` / `SUIT_H10_Binary_20260716.zip` / `SUIT_ContentsFiles.zip`). 이미 v2.3.0/v2.3.1 기준으로 설치·업데이트하셨다면 추가 작업이 없습니다.

### 준비물 안내

빌드 마무리 단계(업로드용 `.bin` 생성)가 **Python** 을 사용합니다. 아직 설치하지 않았다면 [개발 환경 구축](https://github.com/AGR-EXO/Extension_Module/blob/v2.4.0/docs/getting-started/02-software-setup.md) 의 안내대로 Python 3.10+ 를 설치해 주세요 (PATH 등록 필수).

## 개선 상세

### USB 시리얼 (핵심)

- **텍스트 예제 자동 정리** — Ex.07 (`07_CDC_Basic_Print`) · Ex.08 (`08_CDC_Sensor_Print`) 이 `Control_Setup()` 에서 호스트 프로파일을 `TERMINAL` 로 지정합니다. 1kHz 실시간 데이터 전송(auto-pump)이 꺼져, 일반 시리얼 터미널에 깨끗한 텍스트만 나옵니다. DTR 조작이 더 이상 필요 없습니다.
- **모드 관리 내부 이관** — USB 통신 모드 상태 관리를 시스템 레이어로 옮기고, 사용자에게는 프로파일 2가지(PhAI Studio / 터미널)만 노출하도록 정리했습니다. 생산 검사 모드 진입은 내부 자동 처리로 바뀌었습니다.

### 부트로더 디버그 문서

- 디버그 설정에서 **벡터 테이블 주소 `0x08040400`** 를 지정하도록 문서를 보강했습니다. 이 값을 비워두면 디버거가 signal handler 에서 멈추는 증상이 있었습니다.
- 디버그 시작 시 **`main()` 에서 자동 정지하는 것은 정상**(CubeIDE 기본 동작)이며, `Resume`(F8) 로 진행하면 됨을 안내했습니다.

### 안정성 · 빌드

- **GRF 센서 모듈 안정성 추가 개선** — 오류(fault) 발생 시 센서 전원을 재순환(power cycling)하던 동작을 비활성화해, 불필요한 리셋 반복을 줄였습니다. (v2.3.1 의 GRF 부팅 안정화에 이은 후속 개선)
- **MCU 리셋 핀 처리 정리** — 리셋 핀을 released 상태로 유지해 외부 리셋 오동작 여지를 없앴습니다.
- **CubeIDE 빌드 파이프라인 견고화** — pre-build 스크립트를 단일 진입점으로 통합해 CubeMX 코드 재생성 시 빌드가 깨지던 여지를 없앴고, 미사용 USB 클럭 설정을 자동 정리, LwIP(Ethernet) 헤더 경로를 자동 반영하도록 했습니다.

## 호환성 안내

| 항목 | 영향 |
|------|------|
| 사용자 코드 (`Control_Setup` / `Control_Loop`) | **대부분 변경 없음** — 단, `XM_USB_SetMode()` 계열을 직접 쓰던 코드는 위 ⚠️ **API 변경** 의 마이그레이션 참고 |
| `XM_USB_SetMode` / `GetMode` / `Mode_e` 계열 | **제거** — `XM_USB_SetHostProfile()` 로 대체 |
| 그 외 API 시그니처 | 변경 없음 |
| Rev 1.1 SDK | **v2.3.1 그대로** — 이번 릴리즈 대상 아님 |
| KIT H10 펌웨어·컨텐츠 파일 | **v2.3.0 그대로** — 추가 업데이트 불필요 |
| 부트로더 | **v1.1.0 그대로** — 재설치 불필요 |
| 사용자 데이터 (USB 메모리 로그 등) | 변경 없음 — 데이터 포맷 호환 |
