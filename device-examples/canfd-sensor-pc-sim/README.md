# CAN-FD 내 장치 PC 시뮬레이터 (Ex.45 의 상대)

XM10 예제 [Ex.45 CAN-FD My Sensor](../../examples/45_CANFD_My_Sensor/) 의 상대 장치를 PC 에서 흉내 냅니다. [STM32G474 참조 장치](../canfd-sensor-stm32g474/)와 같은 규칙으로 주고받으니, 장치를 만들기 전에 XM10 쪽을 먼저 시험할 수 있습니다.

> 🧰 **필요한 것: CAN-FD(5 Mbit/s)를 지원하는 USB 어댑터 + Python 3.9 이상 + python-can**

---

## 준비

1. `pip install python-can`
2. 어댑터 드라이버를 설치합니다(python-can 이 CAN-FD 로 지원하는 어댑터 — PEAK PCAN-USB FD · Kvaser · Vector 등).
3. 배선 — 어댑터의 CAN_H · CAN_L · GND 를 XM10 CAN-FD #2 포트의 같은 이름에 연결합니다. 버스 양 끝에 120 Ω 이 있어야 합니다. XM10 보드에는 이미 있으므로 어댑터 쪽 끝에 하나를 둡니다.
4. XM10 에 Ex.45 를 올립니다.

## 실행

```bash
python canfd_sensor_sim.py --interface pcan --channel PCAN_USBBUS1
```

| 옵션 | 기본 | 뜻 |
|------|------|------|
| `--interface` · `--channel` | (꼭 줌) | python-can 의 어댑터 이름과 채널 |
| `--node` | `0x20` | 장치 번호 — XM10 예제의 `MY_DEVICE_ID` 와 같게 |
| `--period-ms` | `10` | 주기 데이터 간격. PC 는 1 ms 를 고르게 지키기 어려워 10 ms 로 둡니다 |
| `--sync` | — | XM10 이 보내는 동기 신호(ID `0x080`) 직후에 보냅니다 — 예제의 `MY_USE_SYNC` 를 `true` 로 |
| `--f-clock-mhz` | `80` | 어댑터의 CAN-FD 클럭. 80 이면 XM10 과 같은 값을, 다르면 같은 샘플 포인트(75 %)로 계산해 넣습니다 |
| `--timing none` | — | 어댑터 설정을 그대로 씁니다(밖에서 속도를 정하는 어댑터) |

어댑터 없이 이 PC 안에서만 돌려 보려면 `--interface virtual --channel demo` 를 씁니다(XM10 과는 연결되지 않습니다).

## 하는 일

| 무엇을 | 내용 |
|------|------|
| 주기 데이터 | ID `0x180 + n`, 16 바이트 — 카운터(uint32) · 가짜 ADC 2채널(사인 · 삼각 파형, 0 ~ 4095) · 나머지 0 |
| 살아있음 | ID `0x700 + n`, `0x05`, 1 초마다. 켜질 때 `0x00` 한 번 |
| 명령 받기 | ID `0x200 + n`, `[순번, LED]` — 새 명령이면 화면에 `LED 명령: 켬` · `끔` |
| 화면 | 1 초마다 보낸 수 · 못 보낸 수 · 명령(새 · 버림) · 동기 신호 수 · 그 밖에 받은 수 |

`xm10` 도구의 `0xF0` 탭에서 `ADC0` · `ADC1` 이 파형으로 움직이고, XM10 의 버튼 1 을 누르면 화면에 LED 명령이 찍힙니다. (보드 확인 전) <!-- board-check -->

## 흔한 증상

| 증상 | 원인 | 확인 |
|------|------|------|
| XM10 LED 1 이 느리게 깜빡임(끊김) | 속도 · 샘플 포인트가 다름 · 종단 저항 없음 · 장치 번호가 다름 | `--f-clock-mhz` · 배선 · `--node` |
| 어댑터를 여는 데서 오류 | 어댑터가 CAN-FD 를 지원하지 않음 · 드라이버 없음 · 채널 이름이 다름 | 어댑터 설명서와 python-can 의 그 어댑터 안내 |
| 그래프가 고르지 않음 | PC 가 바빠 보내는 간격이 흔들림(카운터는 보낸 것만 세서 `Skipped` 는 늘지 않습니다) | `--period-ms` 를 늘려 보세요 |
| `Skipped` 가 늘어남 | 버스에서 메시지를 잃음 | 배선 · 종단 저항 · 화면의 '못 보냄' 수 |
